# LaslesVPN

## Project Overview
LaslesVPN is a website for purchasing virtual private networks (VPNs). It offers both free and paid VPN services with various features. The project was designed based on a **Figma** template and focuses on providing a responsive and well-structured user experience.

## Technologies Used
- **HTML** – Structuring the webpage  
- **CSS** – Styling the website  
- **Flexbox** – Flexible layouts for components  
- **CSS Grid** – Grid-based layouts for better responsiveness  
- **SASS** – Enhanced CSS with variables and mixins  
- **Responsive Design** – Ensuring adaptability on different devices  

## Features
- Free and paid VPN plans  
- Fully responsive design  
- Modern layout with smooth user experience
